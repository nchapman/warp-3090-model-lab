# Qwen3.5-9B-W4A16-GPTQ

INT4 weight-only GPTQ quantization of [Qwen/Qwen3.5-9B](https://huggingface.co/Qwen/Qwen3.5-9B)
for memory-constrained single-GPU serving.

## Quantization recipe

- W4A16 (INT4 weights, BF16 activations), group 128, act-order,
  compressed-tensors (pack-quantized) — vLLM Marlin kernels
- Calibrated with [llm-compressor](https://github.com/vllm-project/llm-compressor)
- Calibration set: **`calib-cascade-v1`** — 999 conversations sampled at
  dataset-native proportions from
  [nvidia/Nemotron-Cascade-2-SFT-Data](https://huggingface.co/datasets/nvidia/Nemotron-Cascade-2-SFT-Data)
  (~2.6M effective tokens). The exact rows are hash-pinned in
  [warp-3090-quant-lab-frozen-data](https://huggingface.co/datasets/nchapman/warp-3090-quant-lab-frozen-data)
  — that pin is the citable calibration generation. (A `-cascade` suffix on
  local paths in the [lab repo](https://github.com/nchapman/warp-3090-quant-lab)
  refers to the same generation; this repo carries only the current one and
  supersedes the initial pre-cascade calibration.)

## Fidelity vs BF16 base (378-conv multi-domain probe + external OOD guard)

- weighted KL: **0.089**; guard perplexity delta: **+0.77%**
- per-domain KL: chat 0.033, math 0.023, IF 0.039, science 0.049,
  multilingual (9 langs) 0.083, terminal-agent 0.65

## Usage (vLLM)

```python
from vllm import LLM
llm = LLM(model="nchapman/Qwen3.5-9B-W4A16-GPTQ")
```

Chat template: froggeric v22.5. Sampling defaults follow the Qwen3.5 family
recommendation (temperature 1.0, top_p 0.95, top_k 20).
