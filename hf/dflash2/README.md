# Qwen3.5-4B-DFlash2

DFlash2 speculative drafter for [Qwen/Qwen3.5-4B](https://huggingface.co/Qwen/Qwen3.5-4B).
One recipe, one checkpoint: the epoch-4-of-6 snapshot, selected by deterministic
(greedy) ladder measurement.

## Acceptance (τ — interval-weighted, 20-prompt chat ladder; GB10 serving)

| config | τ, greedy (temp 0) | τ, temp 1.0 |
|---|---|---|
| [Qwen3.5-4B-W4A16-GPTQ](https://huggingface.co/nchapman/Qwen3.5-4B-W4A16-GPTQ) verifier (training verifier) | **4.19** (n=2: 4.218/4.171) | 3.27 (n=2: 3.441/3.099) |
| Qwen3.5-4B bf16 base | 4.15 | — |
| native MTP k=3 (baseline, same ladder) | 2.99 | 2.66 |

Beats the model's native MTP by ~+1.2 τ (greedy) / +0.6 τ (temp 1.0) in every
measured config, and drafts against both the W4A16-GPTQ quant it was trained
on and the bf16 base.

**Measurement honesty:** the temp-1.0 ladder is heavy-tailed — we observed a
0.34 spread on identical inputs across runs. Greedy ranking is the selection
instrument (repeat spread ~0.05); temp-1.0 numbers above are reported with
their spread rather than as point estimates.

## Selection

All six epochs' checkpoints ranked on the greedy ladder: τ rises through
epoch 4 (3.52 → 3.73 → **4.19**) and declines by epoch 6 (4.07) while training
loss keeps improving — acceptance peaks mid-run, so the artifact is the
epoch-4 snapshot, not end-of-training.

## Recipe

- Corpus: 260M tokens — 100k Nemotron-Cascade-2 conversations with assistant
  turns **regenerated by the deployed W4A16-GPTQ quant** (the drafter learns
  exactly what its verifier emits), 6-tap hidden states
- Training: lr 6e-4, cosine schedule, 4% warmup, 6 epochs; block 16 /
  15 spec tokens
- Data lineage: slice ids frozen in
  [warp-3090-quant-lab-frozen-data](https://huggingface.co/datasets/nchapman/warp-3090-quant-lab-frozen-data);
  corpus rebuildable via the
  [warp-3090-quant-lab](https://github.com/nchapman/warp-3090-quant-lab) pipeline

## Requirements

speculators 0.8.1 · vllm 0.31.0 · transformers 5.16.1 · torch 2.13.0
(compressed-tensors 0.17.0). Ships `config.py` — load with trust in remote
code. If speculative serving wedges during CUDA-graph capture, serve with
`--enforce-eager`.
