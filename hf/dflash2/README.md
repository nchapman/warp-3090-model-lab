# Qwen3.5-4B-DFlash2

DFlash2 speculative drafter for [Qwen/Qwen3.5-4B](https://huggingface.co/Qwen/Qwen3.5-4B).
One recipe, one checkpoint: the ladder-selected champion. Acceptance peaks at
**epoch 2** of the winning high-LR run and degrades while training loss still
improves, so this is deliberately not a final-epoch model — selection is by
serving acceptance, never by validation loss.

## Acceptance (τ — interval-weighted, 20-prompt chat ladder, temp 1.0)

| verifier | B200 (original harness) | GB10 (fresh spot-check) |
|---|---|---|
| [Qwen3.5-4B-W4A16-GPTQ](https://huggingface.co/nchapman/Qwen3.5-4B-W4A16-GPTQ) (training verifier) | **3.443** | 3.191 |
| Qwen3.5-4B bf16 base | — | 2.992 |
| native MTP k=3 (baseline) | 2.713 | — |

Beats the model's native MTP in every measured config. τ is sensitive to
serving hardware (verifier kernel numerics shift rejection rates) and to
temp-1.0 sampling noise — compare orderings across setups, not absolute
deltas. Training-metric snapshot at the shipped epoch: accept length 3.28,
top-16 oracle 7.05, selector accuracy 0.74.

## Recipe

- Corpus: 260M tokens — 100k Nemotron-Cascade-2 conversations with assistant
  turns **regenerated by the deployed W4A16-GPTQ quant** (the drafter learns
  exactly what its verifier emits), 6-tap hidden states
- Optimizer: lr 6e-4, cosine, 4% warmup; block 16 / 15 spec tokens
- Data lineage: slice ids frozen in
  [warp-3090-quant-lab-frozen-data](https://huggingface.co/datasets/nchapman/warp-3090-quant-lab-frozen-data);
  corpus rebuildable via the
  [warp-3090-quant-lab](https://github.com/nchapman/warp-3090-quant-lab) pipeline

## Requirements

speculators 0.8.1 · vllm 0.31.0 · transformers 5.16.1 · torch 2.13.0
