# warp-3090-quant-lab drafter (v4 champion)

The DFlash2 speculative drafter for [nchapman/Qwen3.5-4B-W4A16-GPTQ](https://huggingface.co/nchapman/Qwen3.5-4B-W4A16-GPTQ).
One recipe, one checkpoint: this is the ladder-selected champion — not the
final epoch, and not a version family.

## Results (ladder-20, interval-weighted acceptance, temp 1.0)

| config | τ |
|---|---|
| **b16 native (block 16 / 15 spec tokens)** | **3.443** |
| b8 serve-down | 3.131 |
| native MTP baseline | 2.71 |

Training-metric snapshot (epoch 2): accept length 3.28, top-16 oracle 7.05,
selector acc 0.74.

## The winning recipe (v4 armB, stop @ epoch 2)

- Corpus: 260M tokens — 100k Nemotron-Cascade-2 conversations, assistant turns
  **regenerated by the deployed quant itself** (quant-alignment: the drafter
  targets exactly what the verifier emits), 6-tap fp8 states
- Optimizer: lr 6e-4, cosine, 4% warmup, gamma 7 decay, max-anchors 512
- Selection: **ladder-eval every epoch, keep the best** — acceptance peaks at
  epoch 2 and degrades while val loss still improves (the KL/selector training
  objective diverges from serving acceptance at high LR; never select by val
  loss or finality)
- Data lineage: slice ids frozen in
  [warp-3090-quant-lab-frozen-data](https://huggingface.co/datasets/nchapman/warp-3090-quant-lab-frozen-data)
  (`conv-ids/v4.json`); regen corpus rebuildable via the
  [warp-3090-quant-lab](https://github.com/nchapman/warp-3090-quant-lab) pipeline
