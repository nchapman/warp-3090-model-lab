# External references — DFlash-family speculator literature & ecosystem (2026-10-17)

**Purpose:** drawing-board doc for the next drafter campaign. Everything here
is external — library source code and published papers/announcement posts,
verified from primary sources on 2026-10-17 (paper full texts fetched from
arXiv HTML). No lab measurements appear in this doc. Bars quoted from these
references are the reference-conformance targets; the published idiom is the
recipe the next campaign runs.

## 1. `speculators` 0.8.1 defaults for `--speculator-type dflash2`

From `speculators/train/config/schema.py` (`_resolve_derived_defaults` and
field defaults). Verified in installed source, not docs.

| setting | dflash2 default | notes |
|---|---|---|
| `num_layers` | **5** | whole dflash family |
| `draft_arch` | `qwen3` | anything non-eagle3 |
| `block_size` | **8** | → 7 speculative tokens (`sample_from_anchor=False`) |
| `loss_fn` | **`kl_div`** | |
| `per_position_loss_weight` | **`fixed-exp-decay`** | *not* D-PACE — see table 2 |
| `dflash_decay_gamma` | **4.0** | matches paper's γ for block 8 |
| `dpace_alpha` | 0.5 | only used if dpace selected (requires `loss_fn=ce`) |
| `max_anchors` | **512** | masked blocks sampled per sequence |
| `target_layer_ids` | `[2, n//2, n−3]` | even spread, 3 taps by default |
| `sliding_window` | 2048, all draft layers | |
| `sliding_window_non_causal` | **True** (dflash2 only) | bidirectional attention inside blocks |
| `conv_kernel_size` / `conv_group_size` | **2** / **16** | the DFlash2 two-tap local conv |
| `selector_rank` / `selector_top_k` | **256** / **16** | pairwise path selector |
| `selector_loss_alpha` | 1.0 | K-way CE term weight |
| `loss_implementation` | `fused` | `eager` is for numerical validation, may OOM |
| `lr` | 1e-4 | `muon_lr` defaults to **10×lr** (Muon group) |
| `epochs` | **20** | |
| `draft_attn_impl` | `simple_flex_attention` | `sdpa` fallback |

### 1.1 Plain `dflash` differs — the trap in "dflash defaults"

Conditional defaults resolve per speculator type
(`is_dflash = speculator_type == "dflash"`):

| setting | `dflash` | `dflash2` | `dspark` |
|---|---|---|---|
| `block_size` | **16** | 8 | 8 |
| `loss_fn` | **`ce`** | `kl_div` | `kl_div` |
| `per_position_loss_weight` | **`dpace`** | `fixed-exp-decay` | `fixed-exp-decay` |
| `sliding_window_non_causal` | False | **True** | False |
| `sample_from_anchor` | False | False | **True** |

The schema docstring is explicit: the plain-dflash combo (5 layers, D-PACE,
CE, block 16) comes from speculators issue #979 and "outperformed the prior
defaults across every DFlash configuration tested" — while **dflash2
deliberately keeps block 8 + fixed exponential decay + KL "for direct
comparison with DSpark."** D-PACE is the default only for plain `dflash`;
the γ static-decay story is the dflash2/DSpark path.

**Key mismatch to remember:** the library's `dflash2` default is a
DSpark-comparable configuration (b8 / KL / γ=4 / 3 taps / 20 epochs) — *not*
the DFlash paper's flagship recipe (b16 / CE / γ=7 / 5 taps / 6 epochs).

## 2. DFlash paper — arXiv:2602.06036v2 (ICML 2026, z-lab; github.com/z-lab/dflash)

### 2.1 Training recipe (§5, §A.1)

| item | value |
|---|---|
| data | **~800K samples**: Nemotron Post-Training Dataset V2 + CodeAlpaca, responses **regenerated by the target model** |
| ablation-arm data | UltraChat + ShareGPT (EAGLE-3's exact data), 100K; long-ctx arm: LongAlign-10K (1.6K samples) |
| epochs / optimizer | **6**, AdamW, **lr 6e-4**, cosine, warmup ratio 0.04, grad clip 1.0 |
| max sequence length | **3072** (4096 for Qwen3-Coder) |
| anchors | 512 per sequence, **randomly re-sampled every epoch** |
| draft layers | **5** (8 for Qwen3-Coder) |
| block size | **16** (Qwen3), 10 (LLaMA-3.1) |
| target taps | **5 layers** uniformly in [layer 2, third-to-last] |
| loss | **CE with exponential position decay** w_k = exp(−(k−1)/γ); **γ = 7 / 5 / 4 for block 16 / 10 / 8** |
| eval protocol | τ = mean acceptance length, **t=0 and t=1** (no 0.7 anywhere), 2048 max generated tokens; GSM8K, MATH-500, AIME25, HumanEval, MBPP, LCB, MT-Bench |
| EAGLE-3 baseline | draft steps 7, top-k 10, tree 16 (budget-matched) and 60 (their paper's max) |

The paper never uses KL or D-PACE — plain CE with static γ decay. KL-div
and D-PACE are library-layer choices.

### 2.2 Headline results

| result | number |
|---|---|
| max lossless speedup (abstract) | **>6×** |
| best speedup vs EAGLE-3 (abstract) | **up to 2.5×** |
| avg speedup, greedy (Table 1, Qwen3 instruct) | **4.9×** = 2.4× over EAGLE-3(16) |
| avg speedup, t=1 | **4.1×** = 2.2× over EAGLE-3(16) |
| reasoning models, thinking on (Table 2) | ~4.5× / 3.9× |
| SGLang FA4 (Table 3) | up to **5.1×** (Qwen3-8B), holds across conc 1–32 |
| Q3-4B EAGLE-3(16) greedy reference row | 1.81×, τ 3.05 (EAGLE-3(60): 2.08×, τ 3.48) |

### 2.3 Ablation numbers (τ, greedy unless noted)

| ablation | numbers |
|---|---|
| **Block size × train/test mismatch** (8 layers, 5 taps; Math500 / HumanEval / MT-Bench) | b16→b16: **6.33 / 5.29 / 3.50**; b16→b8: 5.09 / 4.44 / 3.18; b8→b8: 5.21 / 4.61 / 3.29; b8→b16: 5.02 / 4.28 / 3.09 — train-big serve-small works, reverse doesn't |
| **Random anchor sampling** (3 layers, 100K data) | standard: 4.94 / 3.86 / 2.80 → sampled: **5.64 / 4.61 / 3.18** |
| **No target features** (Table 10) | speedup collapses to ~2–3× — conditioning is the method |
| **Draft layers** (Table 6) | 8 layers → longer τ; **5 layers → best speedup** (cost/quality balance) |
| **Taps** (Table 7) | more target layers → τ rises monotonically |
| **LLaMA-3.1-8B, B200, conc sweep** (Table 5) | DFlash(10) avg τ **3.73** vs EAGLE-3(10) 3.49, EAGLE-3(60) 4.07 — E3(60) collapses 1.8×→0.5× from conc 1→32 while DFlash holds 2.2×→1.4× |
| **Long context** (Table 4) | 4K-trained base degrades past 4K ctx; 3 epochs on 1.6K LongAlign samples restores/improves τ |
| **Loss decay** (Fig. 5) | decay > uniform for convergence speed and final τ |

## 3. DSpark paper — arXiv:2607.05147v1 (DeepSeek)

Semi-autoregressive drafter + confidence-scheduled verification.
**Deployed in production with DeepSeek-V4-Flash/Pro (preview), superseding
MTP-1 two weeks after the V4-preview release.** A shallow 2-layer DSpark
beats a 5-layer DFlash (Fig. 3); the AR/sequential component is where the
parameter efficiency lives.

### 3.1 Recipe

| item | value |
|---|---|
| data | **Open-PerfectBlend (mlabonne), 1.3M samples** — chat 17.6% / math 39.4% / code 38.9% / IF 4.1%; **prompts only**, responses regenerated by each target at its "recommended sampling parameters" |
| epochs | **10** ("to ensure full convergence") |
| sharing | frozen target embedding + LM head; only backbone drafter, sequential block, confidence head train |
| mode | non-thinking |
| eval | τ per decoding round **@ t=1.0, includes bonus token**, chain-based drafting, scheduler disabled for offline τ |

### 3.2 Numbers (Table 1, τ @ t=1.0 incl. bonus)

| target | drafter | math (GSM8K / MATH / AIME25) | code (MBPP / HumanEval / LCB) | chat (MT-Bench / Alpaca / Arena-Hard) |
|---|---|---|---|---|
| Qwen3-4B | Eagle3 | 5.14 / 4.62 / 3.92 | 3.69 / 4.16 / 3.77 | 2.39 / 2.26 / 2.55 |
| Qwen3-4B | DFlash | 5.40 / 4.85 / 4.15 | 4.40 / 4.74 / 4.18 | 3.07 / 2.96 / 2.83 |
| Qwen3-4B | **DSpark** | **6.11 / 5.70 / 4.89** | **5.13 / 5.38 / 4.86** | **3.64 / 3.54 / 3.29** |
| Qwen3-8B | Eagle3 | 5.30 / 4.77 / 3.91 | 3.96 / 4.33 / 4.17 | 2.66 / 2.54 / 2.54 |
| Qwen3-8B | DFlash | 5.33 / 4.91 / 4.07 | 4.36 / 4.64 / 4.39 | 3.11 / 2.98 / … |

Macro-average τ improvements: over Eagle3 **+30.9 / +26.7 / +30.0%** and
over DFlash **+16.3 / +18.4 / +18.3%** (Qwen3-4B / 8B / 14B). Domain effect:
structured tasks far above open-ended chat (their Qwen3-4B means: math 5.57,
code 5.12, chat 3.49).

**All trained checkpoints released** (Eagle3, DFlash, DSpark for
Qwen3-{4,8,14B} + Gemma4-12B) via the **DeepSpec repository** — runnable
external bars, not just table numbers.

## 4. DFlare paper — arXiv:2606.02091v2

Scales draft *capacity*: each draft layer attends to its own **learnable
combination of a broad set of target layers** (layer-wise fusion /
heterogeneous KV projections) instead of 5 fixed taps — injecting richer
target knowledge and giving every draft layer a distinct input, which
unlocks depth scaling (5/6/7 layers keep improving) and tap scaling
(T: 5 → 9 improves τ and speedup monotonically).

### 4.1 Recipe

| item | value |
|---|---|
| data | **2.4M samples**: Nemotron-PT-V2 + CodeAlpaca + Step-3.5-Flash-SFT; prompts only, **responses regenerated at t=0.6** |
| epochs / optimizer | 6, AdamW 6e-4, cosine, warmup 0.04, clip 1.0 (identical to DFlash) |
| max seq / anchors | 3072 / 512 (identical to DFlash) |
| loss | **progressive position-weighted loss: γ₀=4.5, γ += 1 each epoch** (small γ concentrates on early positions early; grows to cover tails). GPT-OSS-20B keeps γ=4 fixed (block 8 — schedule has little room) |
| batch | global batch 64 (ablations 32) |
| compute | 32 GPUs: ~160 h for Qwen3-8B, ~100 h Qwen3-4B, ~90 h GPT-OSS-20B |

### 4.2 Numbers

| result | number |
|---|---|
| greedy wall-clock speedup | **5.52×** (Qwen3-4B), **5.46×** (Qwen3-8B), 3.91× (GPT-OSS-20B) — +10.6 / +8.1 / +5.4% over DFlash |
| τ vs DFlash, greedy | **+15.5%** (Qwen3-4B), +14.7% (8B), +5.8% (GPT-OSS-20B) |
| τ vs DFlash, stochastic | +10.9 / +11.3 / +3.9% (all methods lose τ under sampling; margins hold) |
| **data-scaling curve** (Qwen3-8B, t=0, avg τ) | **270K → 4.90; 800K → 6.59; 2.4M → 7.33** (Fig. 1 right / Table 6: MATH500 τ 5.19 → 8.23 → 8.95) |

The data-scaling curve is the cleanest published statement of
"data volume still pays at 800K+ with a 5+ layer drafter" in this family.

## 7. Open reconciliation items (before the next campaign quotes any bar)

1. **The "DSpark 100K prompts ≤1024 → 3.41" citation needs re-verification.**
   The DSpark paper itself trains on **1.3M Open-PerfectBlend prompts for 10
   epochs** with chat τ 3.29–3.64 on Qwen3-4B. The 100K/≤1024 variant looks
   like a speculators-side recipe example, not the paper's headline config.
   Pin down which artifact produced 3.41 before treating it as *the* DSpark bar.
2. **Regen temperature idiom is not settled across papers**: DSpark —
   "recommended sampling parameters" (unspecified); DFlare — **t=0.6**;
   DFlash — unstated. A direct input to next-campaign regen design.
3. **Eval temperature conventions differ**: DFlash/DFlare report t=0 and t=1;
   DSpark t=1.0 with bonus token included; the DFlash2 announcement uses
   t=1.0 / top-p 0.95 / top-k 20 / presence 1.5. State convention with every
   quoted τ; never compare across conventions.
4. **Nobody ablates data mix** (PerfectBlend is treated as a constant across
   the ecosystem) and **nobody reports quantized-target results** (every
   published number is a bf16 verifier). These two axes are unclaimed
   territory — publishable if measured cleanly.
